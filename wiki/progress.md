# Текущее состояние

Обновлено: 2026-11-11.

## Реализовано и опубликовано в `main`

- Настройки цвета относятся к каждой серии графика отдельно: `N` серий дают `N` цветовых параметров.
- Для выбора цвета используется системный `input[type=color]`; кнопки с готовыми цветовыми пресетами удалены.
- У каждой серии есть отдельный сброс к стандартному режиму. Стандартный режим сохраняет автоматическую окраску сегментов: рост — зелёный, снижение — красный.
- Цвет серии сохраняется через API и поле `series_color`; для него есть миграция `0006_widget_series_colors`.
- По последней просьбе пользователя толщина линий данных уменьшена вдвое и на графиках карточек, и в предпросмотре создания виджета. Текущие значения: основная линия `3 → 1.5px`, тренд `2.3 → 1.15px`, скользящее среднее `2.8 → 1.4px`, линии в предпросмотре `2.4 → 1.2px`. Размеры маркеров точек оставлены прежними. Правка: `Front-end/app/src/styles/kpi.css`.
- Сетка виджетов использует 12 колонок и сохраняемые координаты `gridX`/`gridY`; помощники раскладки предотвращают пересечения, включая плитку добавления.
- Перетаскивание реализовано через Pointer Events: можно начать с пустой области карточки, виджет отделяется после порога движения, следует за указателем, а сетка показывает позицию предпросмотра.
- Соседние карточки перестраиваются с FLIP-анимацией. Позиции отправляются на API после отпускания; отмена и ошибка сохранения возвращают исходную раскладку.
- Создание и изменение размера ищут свободное место. На узком экране сохраняется одноколоночная раскладка без перезаписи координат широкого экрана.
- Локальный Compose-стек включает React UI, FastAPI и отдельную PostgreSQL; база закреплена за постоянным именованным volume.

- При наведении на точку графика всплывающая подсказка показывает её сохранённый комментарий. Отображение комментария уже было в активной реализации.
- Для администратора добавлено копирование выбранного виджета сочетаниями `Cmd/Ctrl+C` и `Cmd/Ctrl+V` в пределах текущего дашборда. Копия сохраняет описание, серии, оси, цвета, диапазон периодов, настройки трендов и размеры; ей назначается свободное место, а к названию добавляется локализованное «копия».
- Подпись скользящего среднего убрана из обычного потока легенды и размещена поверх строки осей. Она больше не добавляет строку легенды и не уменьшает область графика.
