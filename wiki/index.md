# Wiki проекта KPI Dashboards

Обновлено: 2026-11-11. Последняя передача контекста: функции графиков опубликованы в `main`; UI после пересборки требует повторного входа.

Эта Wiki описывает продуктовые требования, текущее состояние реализации, локальный запуск и незакрытые проверки. Секреты и содержимое локальных `.env` сюда не записываются.

## GitHub и локальные секреты

- Репозиторий: [voyfur/kpi_dashboard](https://github.com/voyfur/kpi_dashboard), основная и единственная ветка — `main`.
- Локальные Compose-пароли находятся в корневом `.env`; пароль dev-входа — в `Back-end/.env` под ключом `KPI_DEV_AUTH_PASSWORD`. Файлы игнорируются Git; значения сюда не копировать.
